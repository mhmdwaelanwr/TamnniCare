# 3) Exact Screens You Should Search / Collect

## A. Senior Home
Look for references with:
- big greeting
- one strong main action
- calm status card
- next reminder card
- simple emergency/help button

### Ideal layout traits
- very large CTA
- low clutter
- high contrast
- comfortable spacing
- 1–3 main items visible without too much scrolling

---

## B. Caregiver Home
Look for references with:
- daily overview
- check-in status
- medication snapshot
- active alerts section
- quick contact action

### Ideal layout traits
- summary first
- simple status chips
- clean cards
- strong hierarchy
- not too many charts

---

## C. Onboarding
Look for:
- minimal onboarding slides
- friendly illustrations
- strong title + short subtitle
- simple CTA buttons
- role selection examples

### Avoid
- too much text
- long carousels
- complex feature explanation

---

## D. Medication Screen
Look for:
- list of medications
- next dose display
- taken / snooze buttons
- clean schedule layout
- easy scanning

---

## E. Alerts Screen
Look for:
- missed check-in alert card
- help request alert card
- read / unread state
- resolved / unresolved badge
- quick action row

---

## F. Profile / Settings
Look for:
- language settings
- notification settings
- linked family section
- account basics
- very clean list layout

# 6) Notes You Should Keep While Collecting

For every screenshot or app example, ask:

- What is good here?
- What is bad here?
- Is the button big enough for a senior?
- Is the page too crowded?
- Is the wording simple?
- Does it feel calm?
- Does it feel trustworthy?
- Would my app user understand this quickly?
