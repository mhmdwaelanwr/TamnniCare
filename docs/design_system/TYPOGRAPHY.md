# Tamnni Care — Typography

## Goal
Typography should feel:
- warm
- readable
- calm
- modern
- accessible

---

## Font Direction

### Arabic
Recommended:
- Cairo

### Latin / English
Recommended:
- Inter

### Fallbacks
- Android: system sans fallback
- iOS: SF fallback when needed

---

## Type Scale

### Display / Large Branding
- `display-lg`: 36 / 44
- `display-md`: 32 / 40

### Headings
- `heading-xl`: 28 / 36
- `heading-lg`: 24 / 32
- `heading-md`: 20 / 28
- `heading-sm`: 18 / 26

### Body
- `body-lg`: 18 / 28
- `body-md`: 16 / 24
- `body-sm`: 14 / 22

### Labels
- `label-lg`: 16 / 20
- `label-md`: 14 / 18
- `label-sm`: 12 / 16

---

## Role-Based Usage

### Senior UI
- prefer `body-lg` or above
- use larger labels for buttons
- avoid tiny helper text
- prefer short sentences

### Caregiver UI
- can use `body-md`
- support more dense summary info
- still avoid tiny important text

---

## Button Text
- standard primary button: `label-lg`
- senior CTA button: `body-lg` or `label-lg`

---

## Tone Rules
- simple wording
- short labels
- calm language
- avoid medical jargon in primary screens

### Good examples
- أنا بخير
- تم الاطمئنان اليوم
- الدواء القادم
- طلب مساعدة
- آخر تحديث

### Avoid
- heavy medical terminology
- long explanatory paragraphs on key screens
