# Tamnni Care — PRD

## Product Summary
**Name:** طمّني / Tamnni Care  
**Type:** Mobile app for elderly reassurance and family care coordination

## One-line Description
A simple app that helps families stay reassured through daily check-ins, medication reminders, and urgent alerts.

## Problem
Families often worry about elderly parents or relatives who live alone or need regular follow-up.  
Existing solutions are usually too medical, too complicated, or not designed for seniors.

## Main Goals
- Make daily reassurance simple
- Reduce anxiety caused by missed replies
- Support medication adherence
- Keep the first version small and easy to use

## Non-goals for V1
- Live location tracking
- Video calls
- Wearable integration
- Medical device sync
- Doctor consultations
- Advanced AI
- Payments

## Target Users
### Senior User
Needs:
- One-tap “I’m okay” confirmation
- Medication reminders
- A simple help button
- Large, easy UI

### Caregiver / Family Member
Needs:
- Clear daily status
- Alerts if no check-in happens
- Simple view of medication activity

## Core MVP Features
1. Daily Check-in
2. Medication Reminders
3. Missed Check-in Alerts
4. Emergency Help Button
5. Family Connection

## Main Screens
- Splash
- Onboarding
- Language Selection
- Role Selection
- Sign In / Sign Up
- Senior Home
- Caregiver Home
- Medication List
- Alerts
- Profile

## Success Metrics
- Daily check-in completion rate
- Medication confirmation rate
- Missed check-in alert rate
- 7-day retention
- 30-day retention

## Final Product Statement
**Tamnni Care** helps families stay reassured through daily check-ins, medication reminders, and missed-response alerts in a calm, simple, elderly-friendly experience.
