# Tamnni Care — UI Brief for Design Chat

## Product
Tamnni Care is a mobile app for elderly reassurance and family care coordination.

## Core Product Promise
Help families feel reassured through:
- daily check-ins
- medication reminders
- missed check-in alerts
- help requests

## Brand Direction
- calm
- safe
- warm
- trustworthy
- simple
- human

## Important UX Principle
This app is **reassurance-first**, not:
- a full health records app
- a medical analytics dashboard
- a caregiver marketplace

## Two UX Modes

### Senior Mode
- very simple
- large buttons
- low clutter
- short labels
- minimal scrolling

### Caregiver Mode
- summary-rich but still clean
- status-oriented
- clear alerts
- quick follow-up actions

## Required MVP Screens
- Splash
- Onboarding
- Language Selection
- Role Selection
- Sign In / Sign Up
- Senior Home
- Caregiver Home
- Medication List
- Medication Details
- Alerts
- Help Request Flow
- Notification Permission
- Profile / Settings

## Visual Direction
Use:
- navy + soft teal + soft white
- rounded cards
- high readability
- large touch targets
- clean hierarchy

Avoid:
- overly clinical design
- dashboard overload
- cold corporate look
- marketplace styling
