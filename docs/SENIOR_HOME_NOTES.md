# Tamnni Care — Senior Home Notes

## Screen Purpose
The Senior Home screen should be the simplest and most important screen in the app.

Its job is to let the senior user:
- understand today's status quickly
- confirm “I'm okay” easily
- see the next medication
- ask for help fast

## Main Sections
1. Greeting
2. Daily Status Card
3. I'm Okay Button
4. Next Medication Card
5. Help Button

## Suggested Layout

### 1. Greeting
Examples:
- صباح الخير
- Good morning
- أهلاً يا Mama / Baba

### 2. Daily Status Card
Should show:
- today's status
- last check-in time
- whether today's check-in is completed, pending, or missed

### 3. Main Action Button
Large primary button:
- **أنا بخير**
- high contrast
- centered
- easiest action on the screen

### 4. Next Medication Card
Should show:
- medication name
- next reminder time
- quick status

### 5. Help Button
Secondary but visible action:
- **طلب مساعدة**
- should feel urgent but not scary

## UX Rules
- very large tap targets
- minimal text
- low visual clutter
- short labels
- calm colors
- strong readability

## First Static Version
The first version of this screen can be UI only, with no backend:
- hardcoded greeting
- hardcoded status card
- hardcoded medication card
- static help button
- static I'm okay button
